# Каталог текстовых RT64-текстур

Этот документ фиксирует результат ручной выборки из полного RT64-дампа
`text_dump`: 106 уникальных PNG, оставленных в `text_decoded/png` как
потенциально относящиеся к тексту. Сами извлечённые из ROM изображения не
хранятся в Git. Каталог нужен для идентификации, сборки составных изображений
и будущей системы замены текстур.

**Решение проекта:** все перечисленные здесь 106 хэшей составляют полный список
известных точек подмены, но языковые комплекты могут быть разреженными. Если в
выбранном английском или русском комплекте есть файл для хэша, используется
перерисованная текстура; если файла нет, игра показывает оригинал. Поэтому
можно заменять только необходимые надписи, а тени, фоновые плашки, управляющие
обозначения, `New`, copyright и части логотипа добавлять лишь при необходимости.
Готовые файлы кладутся в `assets/localization/en/textures` или
`assets/localization/ru/textures`; обе базы
`rt64.json` уже перечисляют все хэши из этого каталога.

Хэш с суффиксом `.v5` — идентификатор RT64 с учётом формата и палитры. Адреса
RDRAM приведены для исследованного дампа и полезны как дополнительное
доказательство, но ключом замены должен оставаться хэш. Один адрес может дать
несколько хэшей при использовании разных TLUT-палитр: `OK` и его чёрная тень
ниже являются подтверждённым примером.

## Локальные собранные результаты

Скрипт исследования соединяет изображения без интерполяции. Для проверенного
дампа результаты размещены вне репозитория в
`text_decoded/assembled`: `title_logo.png`, `title_subtitle.png`, общий лист
названий и каталог `wood_labels/item_01.png` … `item_32.png`.

При создании системы локализации нельзя считать составное изображение одним
RT64-хэшем: игра загружает каждую полосу отдельно. Переведённую картинку нужно
снова разрезать по исходным размерам и связать каждую часть с соответствующим
хэшем из таблицы.
